# T-B195（I1）盘中快照与 1 分钟线字段证据

依据 [T-A209 §0.1–0.4 与 U8](T-A209-market-wiring.md)。本单交付字段证据清单和合成规范化夹具。公开响应沿用 [API §1.1、§5.1、§7.3](../api-contract.md)。下述报价 `basis`、`/quotes` 量额可空化及 `TerminalQuote.volume` 是 T-A209 的拟议增量，正式接线前由 I7/I8 先落实 API 契约。此处 `basis` 属单只证券报价，与市场聚合的 `MarketBasis` 用途不同。

## U8 逐项清单

接口代号 `Q1`、`Q2`、`M` 分别对应上表的单股快照、多股快照、Pro 1m。右列是内部规范化目标，原始键和单位均等允许资料中的已授权脱敏证据对照后再映射。

| 范围 | 待核字段或事实（状态） | 系统口径与缺证处理 |
| --- | --- | --- |
| Q1/Q2/M | 证券代码、市场后缀、产品类型和 ETF 覆盖（未验证） | 必须能证明代码与市场归属；不能按请求顺序指派返回记录，不能用股票样本推出 ETF。 |
| Q1/Q2 | 最新价、参考前收、涨跌幅来源、单位和除权语义（未验证） | `price`、`change_pct` 用十进制字符串，未知为 `null`；缺官方参考前收时不借昨收推导涨跌幅。 |
| Q1/Q2 | `volume` 原始单位及瞬时/累计定义，跨午休或跨日如何重置（未验证） | 已证后转股。未知留 `null`；不能沿用日线手数规则或把累计量当单分钟量。 |
| Q1/Q2 | `amount` 原始单位、精度及累计定义（未验证） | 已证后转元。未知留 `null`；价格、量、额来自同一来源和批次，缺值不拼旧盘量额。 |
| Q1/Q2 | 行情时间、批量时间/缺成员、是否延后更正、竞价与停牌事实（未验证） | 区分行情 `t` 和实际采集 `fetched_at`。用有时区的真实数据时点，不能用请求时间充当 `t`；停牌须有证据。盘中快照不能自动标成收盘。 |
| M | 1m 查询参数、分页/范围、响应标识和 OHLC 原始字段、单位及不复权证据（未验证） | 系统分钟输出为 `freq=1m`、`adjust=none`，OHLC 要完整；缺任一必需值则省略该根。 |
| M | 单根成交量和成交额的字段、股/手/元等原始单位、精度（未验证） | `Bar.volume/amount` 为不可空十进制字符串，单位股和元。未知任一项省根并记 `no_source`；已证零用 `"0"`。 |
| M | 开始/结束标签、时区、最后一根完成性、竞价/午休边界（未验证） | `Bar.t` 为带时区的区间结束时点。T-A209 只允许已完成且可见的分钟；断点不造平价零量 K。 |
| M | 重复或乱序、晚到修订、盘后补齐及 ETF 覆盖（未验证） | 保留行情时点和采集时点；晚到结果只在知识截止之后可见，不能改写旧日报。无证据保持缺口。 |

拟议报价 `basis` 形如 `{mode: "intraday" | "close" | null, trade_date: date | null, source: string | null}`。没有可信归属时各键为 `null`；`data_as_of` 取实际参与数据时点，全部未知为 `null`。内部完成记录需能追溯来源端点、本人证书归属、观察与采集时点、批次和规范化版本。这些是系统元数据，证书和原始负载不进公开响应或夹具。收集证据时逐接口核原字段、单位、观察窗、样本覆盖和修订事实；待 I5/I6 补齐，其余 U1/U2/U9/U10 继续按原单。
