# T-R81 B1–B8 公开日线参考（draft）

用途：后端逐值对照的**缺口/拒绝参考**，仅解释候选信号，不荐股、不承诺收益。
20 只 × 3 个固定评估日 × 8 键＝480 行；正式 `value` 全部为 `null`，每键60行。
**本单尚不能交付非空 B1–B8 数值黄金样本**：指定源缺交易所日历、sf、历史可见/定版证据。
不把已完成的字节复现验收解释为数值口径、停牌、除权覆盖或生产接线验收通过。

## 依据与计算边界

- 唯一规格：PR #205 docs/strategies/T-R78/horizon_inputs_spec.md §2、§3.1–§3.7、§3.11、§3.13、§4（未合入）。
- 裁定：团队报告 T-R78.md「§T-A188 架构师裁定」共同裁定及 Q01/Q02/Q06/Q08/Q11/Q12；「§T-A188 后端单草稿」B1–B8。
- B1=count(上市日≤开市日≤d)，首日1；B2=sum(amount)/n、整数CNY；B3=收益样本std(ddof=1)、ratio六位；B4=mean((h−l)/前有效收盘)、ratio六位。
- B5=(MA20/MA60−1)×100；B6=(c(d*)/c(b*)−1)×100、b=d前60开市日，均pct两位；B7=count(close_raw=规则涨停价)、整数count；B8主因子归一pct四位。
- B2–B7 的15/45覆盖门槛依 Q01 **只可合成试算**；真实数据不擅自采用，也不另定100%门槛。
- qfq@as_of=raw×A(t)/A(d)，只许生效日≤d且可见的事件；共同裁定明确 gbbq 连乘默认不生效，缺因子不补1。脚本没有启用未经裁定的复权公式或 raw 替代值。
- B7需要逐日ST、无限制日、前收/除权参考价；来自 `config/market_rules.yaml` 的分段比例本身不能补齐这些数据。
- B8按Q02不能自动切换本地算法；gbbq无法可靠解出历史流通股本时仍null，不用当前股本回填。
- 三项分位须完整沪深截面（规格§4）；本单只对应原值层，20只样本不冒充截面。北交所标HG2排除及Q06身份缺口。

## CSV 与手算（仅原始诊断，不是非空B值）

`null` 为明确空值；window_start/valid_bars未知写null，window_end仅为请求截止d。停牌不补0、不前填；缺前收/因子不计算收益。
`data_sha256_short` 顺序为日线包、gbbq包SHA256前16位；脚本锁定并校验完整SHA256，不接受其他版本。
`diag_*` 仅在B2/B7行填写：取上证指数截至d最近20个**观察日期**交集，绝不当交易所W20。diag_observed_bars是物理行数，不是有效K数；diag_missing_dates排除首条之前日期。
`diag_amount_sum/mean` 保留原始f32精确值（Decimal.from_float），单位未核，均值仅最终HALF_UP取整。没有样本写null；其他键的诊断留空表示不适用。
`diag_limit_matches/one_price_matches` 用前一条原始收盘作**条件算式输入**，逐段读取规则，对未知ST枚举两种比例；结果带日期@比例，并与close_raw逐分比较。最小价差0.01元；只记匹配，不输出B7计数。它未排除IPO无限制日、未知除权及停牌，不能称已确认涨停。

## 复现与局限

纯标准库；数据只读，选取的21份.day（含指数）及gbbq仅解压到临时目录并自动清理。无网络、数据库、凭据读取，无生产模块导入。
在仓库根目录将DATA设为两包所在目录；无需向脚本提供密钥或配置数据源。

```sh
DATA=../tdx-pack
export PYTHONDONTWRITEBYTECODE=1
python3 docs/strategies/T-R81/gen_reference.py --day-zip "$DATA/hsjday_20261110.zip" --gbbq-zip "$DATA/gbbq_20261110.zip"
python3 docs/strategies/T-R81/gen_reference.py --check --day-zip "$DATA/hsjday_20261110.zip" --gbbq-zip "$DATA/gbbq_20261110.zip"
```

tdx源≠生产源；上市日是代理；缺历史流通股本。gbbq自算复权因子未经官方核对，本单实际未启用；只校验编码容器长度，不把包内记录数当有效权息事件数。
覆盖结论：完成三板块、北交所、新股、缺K、一字价观察；**停牌、真实封板、除权与ST的事实覆盖未完成**。缺K可能是漏数，价格跳变可能另有原因。所有正式值均null是这些约束的结果，不是数据不存在或收益为零。
