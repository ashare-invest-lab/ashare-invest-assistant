## PN-06 断言字段约定

- `cases[].bars` 是主段：每卡 40 个【虚构】交易日，2026-08-03 至 2026-09-25；`warmup_bars` 是额外预热段，S-01/S-02/S-04 各 30 根、W-02 120 根。W-02 主段前 19 日尚不足 140 根，`ready=false`，不产生候选。预热段不产生模拟订单。日期只代表夹具日历，周一至周五的生成规则不代表交易所节假日。
- OHLC、`pre_close`、限价和成交价均为不复权元价；`volume` 为股、`amount` 为元。普通主板、非 ST、非退市整理、已上市满 500 个【虚构】交易日，S-01 为自选股。`list_days` 按此虚构日历逐日递增，不用回填 K 根数推算上市年龄。
- `factor_events` 是同一冻结版本。基准 A=1；2026-09-16 08:30 才可见且当天生效的【虚构】拆股令 A=2。日线/环境 `available_at=17:10`，求值 `as_of=17:15+08:00`。每个 T 独立截断；尚未生效或不可见的事件不能参与历史计算。每根 K 附 A 和 A_available_at，checker 核对事件表。
- 停牌 2026-09-18：OHLC 为 null，量额为 0，不复制前收作为 K。MA/RSI/结构窗口跳过停牌；F01/F11 使用近 20 **交易日**内的有效 K；S-01 均额则取最近有效 K。停牌日 `candidate=false`、`ready=false`、全部 `rules=null`、`exit_rules={}`，metrics 中的 MA 是此前有效序列诊断，`close_qfq=null`。
- `expect.daily` 与主段逐日对齐；必须逐项断言 `date/candidate/ready/rules/triggered_conditions/exit_rules/metrics/environment`。`triggered_conditions` 按 rules 的 E、F、V、C、I 顺序列出 true 项；反证和失效不抵消技术候选。null 表示未裁定/不可求值，不能当 false。`ready=false` 时技术指标仍可作诊断。
- `metrics` 保存每个 T 的 `A_T`、`close_qfq`、MA5/10/20、均额及各卡专项中间量；持仓求值另有 `entry_price_qfq`、三卡的 `structure_threshold_qfq`。RSI 取 2 位、带宽取 6 位、分位取 4 位；F01 四舍五入至整元；其他中间量保存 8 位，计算中不先按 8 位截断。浮点比较容差绝对 1e-7、相对 1e-10；布尔、null、数组顺序及字段集合精确匹配。
- `expect.trade` 仅跟踪本 case 首次候选的一次完整往返。`signal_date` 为候选日；`entry_date/entry_price_raw` 是 T+1 开盘参考成交；`frozen_structure={L_raw,s}` 是信号日尺度的原价位及冻结日。`exit_signal_date` 是首次收盘退出候选日，`exit_reasons` 保留当时全部 true 的 X 编号，不强行选优先级；`exit_date/exit_price_raw` 为实际顺延后模拟执行日及开盘价。
- `stop_trigger_date/stop_execution_date` 专指结构止损；S-01 两项及结构位均为 null，不增设 X4。`execution_blocks` 按日期记录未成交原因。退出触发后保留指令，后续条件变化不撤销、不滚动重选结构位；先执行开盘待办，再求当日收盘条件，退出执行日不再求持仓退出。
- `sellable_at_open` 是【虚构】可卖量存在的证据，不表示真实排队成交；新买股份当日仍不可卖。开盘等于跌停价即不能假定卖出，不用当天高低价证明开盘成交。`exit_after_base_slippage=exit_price_raw×(1−slippage_bp/10000)` 仅扣卡内基础滑点，绝不是扣全成本后的收益。无配置金额及费率，`impact_cost/fees=null`，不填零。

## 各日通用手算公式

对每个 T，先按日期及 available_at 截断，再将全部有效历史 OHLC 重算为 `raw(d)×A(d)/A(T)`；本日 `close_qfq=raw_close(T)`。绝对低价门槛 **2 元**、涨跌停价和一字板始终用 raw。普通主板限价为 `pre_close×1.1/0.9`，以 0.01 元 ROUND_HALF_UP；除权日 pre_close 是显式输入的参考价，checker 不拿昨天 close 猜补。

每个逐日 `explain.process` 列出有效 K 数、qfq 除数、MA5/10/20 的分子和分母及 ADV 分母；对应 `expect.daily.metrics` 是以下比较的逐项代入值。MA_N 为最近 N 根同尺度 close 的和/N，比较用未截断中间值。所有输入及这些工作表也都是【虚构】。

| 卡 | E/F/V/C/I 每日比较（编号顺序同 JSON） |
|---|---|
| S-01 | E1 `c/c[-21]−1≥0.15`；E2 `MA5>MA10>MA20`；E3 `low≤MA10×1.01 且 c≥MA10`；E4 `amount<mean5_valid×0.7`；F1 `mean20_valid≥5000万`；F2 `list_days≥60`；V1 `F50=downtrend`；C1 `raw_close/pre_close−1<−0.05`；C2 `amount>mean20_valid×1.5`；I1 `MA5<MA10` |
| S-02 | E1 最近3根 RSI14 任一 `<30`；E2 `c/c[-6]−1≤−0.08`；E3 `c>前一根high_qfq`；F1 `ADV20≥5000万 且 list_days≥60`；V1 `F25=downtrend`；C1 `c<前收 且 amount>ADV20×1.5`；I1 `c<此前5根最低low`（不含 T） |
| S-04 | E1 T−2 收盘封板、T−1 未封板且 F11≥2；E2 `c>前一日high_qfq`；E3 `amount>ADV20×1.5`；V1 `F25=downtrend`；C1 `raw_close=limit_up`；I1 当根 `c<前2根high` 且前一根 `c<其前2根high`。F11 逐分用原价收盘等于当日涨停价计数，不是连板数；另有上市≥60日门槛 |
| W-02 | E1 当日 BW 分位≤0.2；E2 `c>此前20根最高收盘`（不含 T）；E3 `amount≥ADV20×1.5`；F1 `ADV20≥5000万`；F2 `list_days≥120`；V1 `F25=downtrend`；C1 `raw_close/pre_close−1>0.095`（仅本例主板）；I1 角色待裁定，一律 null |

RSI 从每个 case 固定预热起点重算：前 14 个差值的正负部分分别取简单均值，此后 `(旧均值×13+当次)/14`。总涨跌均为零时 null；只有跌幅均值为零且涨幅正时 100；否则 `100×avg_gain/(avg_gain+avg_loss)`。停牌跳过，不拼接各日 qfq 末值。W-02 BW=`4×总体标准差20/MA20`，分位取最近120个非null带宽，当前值的平均秩/n，至少90个；本例先将各带宽按 F31 取6位后求秩，不把当日收敛改成昨日。

环境单独预热80日。沪深300合成收盘恒1000，中证全指恒2000，故两指数 MA20/60 各为1000/2000。封闭【虚构】市场只有两股，每日一涨一跌且均成交，F24=1/2，20日宽度均值=0.5；因此指数严格大小条件皆不成立，F25/F50每日均为 range，V1=false，连续2日防抖维持 range。这里的“完整”仅指这两股组成的测试世界，不能声称实际沪深宽度覆盖。

## 独立性、自测和限制

checker 从原始 K、可见事件和环境输入重新计算全部160日及4笔交易，递归比对全部 expect；交易日与退出日不从 expected 驱动。三个内存负例均须拒绝：S-01 信号日收盘25.80改25.79（仍为合法 OHLC）；S-02 把18日停牌改为有量有效K（价格合法、应改变最早卖出日）；把重算函数改为全样本末日 A 锚。末日锚负例即使不改变比例条件，也会改变历史 qfq/MA/锚值证据，必须拒绝。自测不写篡改文件。

所有具名默认值和使用的固定窗口见每个 case 的 `params/fixed_params`，共同状态 `parameter_status=未验证`，并有 `unverified` 逐项说明。额外预热不是生产数据就绪证明。环境阈值、防抖、覆盖比例、滑点、计日及拟成交证据均未验证；本例没有 ≥5日长停牌复牌买入、ST/退市、缺 pre_close、复杂因子修订、连续多日跌停、现金分红或数量费用账本覆盖。因子缺失会拒绝输入，不补1。

S-01 仅为 v2 对照，未补 v3 或结构退出；其时间止损 R 未定义，本例未达时间门槛。S-02 QFQ-1、S-04/W-02 QFQ-2 的生产派生仍未实现，本 checker 仅提供参考答案；S-04 高风险默认不启用。W-02 I1 角色、非主板近涨停换算、持有计日和 R 定义仍未裁定，本例持有计日约定为“入场0，按虚构交易日历含停牌计数”，不反向修改卡。行业超额/B11接入/N-01产品门控、策略有效性及G1–G7均未验证。PN-06应保留研究候选和产品阻断的区别。
