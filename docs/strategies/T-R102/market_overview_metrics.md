## 2. 共用时点和范围

### 2.1 观察时点

- T 是交易日历确定的交易日，不能用自然日或当前系统时钟替代。
- 个股收盘行必须是 `trade_date=T`，`fetched_at` 的北京时间不早于 T 日 15:00，且 `fetched_at <= query_as_of`，同时有来源的正式收盘完成事实。仓内日快照继续遵守 `FINAL_AFTER=17:10` 门槛。15:00 后取得的盘中行不能改标为正式收盘。
- 指数也必须有 T 日正式收盘记录并满足查询时点可见性。任何滚动窗口只取 `trade_date <= T` 的已完成交易日。
- `close`、`pre_close`、`high`、`low`、`volume` 以及交易状态均保留原始十进制。相等比较使用 `Decimal` 和最小价位单位，不能用浮点容差。

### 2.3 停牌和零成交量

- `is_suspended=true` 的行，以及交易所或来源明确给出当日无成交且 `volume=0` 的行，不计入上涨、下跌、平盘，也不计入涨跌停、触板或一字板。
- 缺行不能推断停牌。没有停牌事实的缺行进入缺口，不能补成平盘。真实零值保留，字段缺失不补零。
- 上述排除条件和有效分母是**仓内定义**。R6、R7 只证明行情字段和交易接口的公开存在，不能证明供应商已按本卡完成全市场覆盖。

## 3. 市场宽度

### 3.1 上涨、下跌、平盘家数

有效集合 `E_T` 是通过第 2 节时点、`security_type=stock` 且排除 CDR、停牌和零量检查，且 `close` 与 `pre_close` 完整的沪深股票行。定义如下。

```text
up   = count(close > pre_close)
down = count(close < pre_close)
flat = count(close == pre_close)
N    = up + down + flat
内部研究派生：up_share = up / N，down_share = down / N，flat_share = flat / N
```

`up_share`、`down_share`、`flat_share` 是仅供内部研究记录的派生量，不进入 `/market/overview` 响应或前端字段。公开宽度只使用契约五字段 `up`、`down`、`flat`、`limit_up`、`limit_down`。

ST 和其他风险警示股票仍进入三类基础宽度分母。上市首日只有在来源给出有效 `pre_close` 且有成交时才进入宽度。`N=0` 或任一必要来源缺失时，三类家数为 `null`，内部占比也为 `null`，不能把缺失写成平盘。

原始价格、前收和成交量字段的公开接口依据为 R6、R7。有效集合、比较关系、分母和占比是**仓内定义**。本轮不把“上涨占比 50%”“下跌占比 40%”写成有效市场结论，它们属于 F25/G-02 的未验证参数。

### 3.2 涨跌停家数

对每个有效沪深股票行，先按 T 日生效的交易规则取得限制比例 `p_T` 和最小价位单位 `tick_T`，再计算。

```text
limit_up_price   = tick_round(pre_close × (1 + p_T))
limit_down_price = tick_round(pre_close × (1 - p_T))
limit_up   = count(close == limit_up_price)
limit_down = count(close == limit_down_price)
```

- 上交所和深交所规则均规定涨跌幅限制价格为前收盘价乘以 `1±比例`。两所规则均要求按申报价格最小变动单位四舍五入。依据为 R1 第 3.3.13、3.3.17 条和 R2 第 3.3.13、3.3.14、3.3.19 条。
- `tick_round` 使用规则要求的四舍五入到 `tick_T`。交易所资料只作规则参考，不能替代供应商字段验证。中间计算保留 `Decimal` 全精度，只在规则要求的价位单位上取整。
- `pre_close<=0`、除权除息参考关系不明、限制比例或最小价位单位缺失时，该证券不计入涨跌停分母，并记录缺口。不能以统一 `±10%` 反推。
- 证券在无价格涨跌幅限制日不计入涨停、跌停、触板和连板。新股、退市整理期和重新上市的生效日均须按交易所规则逐日判断。

涨跌停价格公式、取整和无涨跌幅日是 R1、R2 的公开规则。来源批次的覆盖、停牌排除、证券状态字段和逐证券规则映射仍待 T-B203 补证，不能因公式已有出处而宣称家数来源已可用。

### 3.4 一字板和触板

交易所公开接口提供日内高、低、开、收和成交字段，依据 R6、R7。下面两项是**仓内定义**。

- **收盘封板**：有有效限制价且 `close == limit_up_price`。涨停家数使用这一条件。跌停对称处理。
- **一字板**：有有效限制价、`volume>0`，并且 `open == high == low == close == limit_up_price`。该定义要求四价相等，不把“收盘封板”自动称为一字板。
- **触板**：有有效限制价、`volume>0`，且 `high == limit_up_price`。`close < limit_up_price` 的触板是曾到涨停但未收盘封住的行。触板数不等于涨停家数，一字板属于触板的收盘封板子集。
- 无限制日、停牌、零量、缺任一所需价格或规则字段时，不判一字板或触板。价格比较先经过同一 `tick_round`，不使用展示字符串近似。

## 5. 缺证、null、gap 和前端展示
