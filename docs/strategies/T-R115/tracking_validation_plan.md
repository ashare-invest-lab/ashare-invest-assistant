# T-R115 未验证参数跟踪验证方案

- lifecycle: draft
- G7: ☐
- 主线现状与要求分开：表内路径和当前值按 `origin/main` 代码与契约字段记录；PR #182 的 `docs/contracts/daily-bars-source.md` §10 只作为待合入收口要求，不写成已实现或已验收。
- 范围：仅用本人持仓、自选和已出建议的自然积累；不跑全市场，不逐标的跑全市场回测。所有字段按其可见时点截断，建议以 `suggestions.created_at`、信号以 `signal_events.quote_ts`/`created_at`、跟踪结果以 `entry_at`/`exit_at` 为准；不得用生成后的字段回填触发时点。
- 共同防过拟合：先登记样本筛选、阈值和公式；前段样本只观察，后段按时间验证；同一批样本不调参又验证；多参数同时检验只报告预注册主指标并注明多重比较；不足时保持未验证与 enabled 现状。以下“统计惯例”仅作最低样本参考，不是项目验收承诺。
