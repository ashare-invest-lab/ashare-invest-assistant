## 3. 数据边界与共同缺口

只假设任务给定的 market.daily_bars（none，含 pre_close、is_suspended，volume 股、amount 元）、通达信 hsjday/gbbq/hf-1min/tdx-min、T-R65 状态输入。hf-1min 从 2022 年起是来源范围，不是对每股每天完整覆盖的声明。主基准为沪深300（000300），辅基准为中证全指（000985），接口见团队报告 T-R72 §7 B11（编排者 11-14 裁定）。基准选择已确定；接口及 tdx 对照的代码/市场映射、覆盖与版本仍未验证。真实指数具体定稿保证时点：未验证（T-R87）。行业超额待 B12 接入后使用申万一级，此前行业超额相关项一律标“未验证”，不以大盘超额替代。本轮不调用麦蕊、不连接行情库、不读取凭据。

每次复测先冻结 source 与版本，跨源作对照，不能逐行择优混拼。T-R65 的状态是已知子集且数据本体未随说明入库：沪市 ST 是公告推断、仍有校准误差；上市状态尾段有 unknown；状态截至窗口之后不延长填充。最新 T-R65 已登记 P9 四分类，不能把 T-R59 的旧缺口描述当成它现在仍全未解决；但该覆盖结论也不能直接外推给麦蕊股票池。来源：docs/strategies/T-R65/README.md §①、§②（P9）、§③。

团队报告 T-A159「*_qfq 口径裁定」及条件 C1：以晚于信号日（如最新日）为锚的前复权仅可用于展示，不得用于候选信号或回测。*_qfq 指 qfq@as_of：以信号日 T 为锚、逐日重算、只用当时可见且已生效的权息因子，等同团队报告 T-R72 §7 B08 权息事件逐日复权，可用于候选信号、指标与回测，字段名不改。历史日 d 的价格为 raw(d)×A(d)/A(T)，T 日值等于不复权价；因子事件日期须≤T 且 available_at≤as_of，缺因子记缺口，不补 1。回测须每个历史 T 独立调用 prepare 或等价重算，不得复用末日锚定序列、拼接不同锚点末值算指标，或用后续修订的因子回写过去候选信号。同一因子版本下，固定基准 hfq 与 qfq@T 仅差正比例常数，比值、均线和结构位同尺度比较等价；绝对元价阈值（如低于 2 元）、一字板与涨跌停价一律用不复权价（none）。收盘、均线、入场价和结构止损/止盈阈值按同一 qfq@T 尺度比较。成交及费用按实际不复权价记账；入场价折算后用于同尺度比较，R 统计仍须核验现金分红、送转股数、持仓权重及费用账本，不直接混减复权价差与不复权每股费用。冻结 source、因子版本及旧快照；事件可见性或复杂权息证据缺失时标“未验证”并阻断相关求值。

字段口径依据团队报告 T-A159：保留 f.*_qfq、plan.entry_price_qfq、ctx.cost_price_qfq、ctx.highest_close_since_entry_qfq 等现有名称，均按 qfq@as_of 使用；成交日价格按 A(成交日)/A(T) 折算。plan.stop_loss_qfq、plan.breakout_level_qfq 的 QFQ-1/QFQ-2 派生尚未实现，三张相关卡的持久化与换算要求见各卡 §7、§9；字段口径裁定不代表派生已经实现。

涨跌停基准严格按不复权 pre_close；缺失或冲突不从 gbbq/昨日 close 猜补。来源：docs/strategies/feature_spec.md §1.3、§F35/F36。

S-01 使用 F50；S-02/S-04/W-02 保留 F25，不能省略宽度；RC3 仍使用 F25。宽度从完整市场的≤T 日 K 与前收重算，行情清单若仅来自今天的存续股票会有幸存者偏差，需按 T-R65 当日状态与终止名单审计。行业超额及其原证伪均未验证；B12 接入后用申万一级，需历史成员及对应指数收益。主辅基准按本节裁定；股票池覆盖与指数源接入仍未验证。来源：docs/strategies/feature_spec.md §F24、§F25、§F50；docs/strategies/validation.md §1.1–§1.3。

## 4. 时点与可执行性

T 收盘后等待北京时间 17:10 后实际定稿及依赖齐全，再冻结候选条件、结构锚点与证据；T+1 开盘只用于成交与成本账本。后续退出也按当日收盘重新计算、下一可卖交易日执行。T+1 新买股份当日不可卖，最早 T+2；不承诺阈值价止损。信号与成交样本分开，次日涨跌停、停牌、ST/上市状态变动造成的不可成交须计数，不能回头删除 T 的候选信号来改善结果。来源：docs/strategies/_template.md §7.2、§7.3、§17、§18；docs/strategies/validation.md §1.4。

结构止损按编排者 11-14 裁定：S-02 X1b 为入场候选日冻结的入场前 5 根有效 K 最低价（含候选日、不含实际入场日）；S-04 X1b 为冻结的断板日高点；W-02 X5 为冻结的前 20 根最高收盘突破位×(1−fail_pct)。按团队报告 T-A159 条件 C2，持久化为「不复权价位 L_raw + 冻结日 s」，每个 T 按 L_raw(s)×A(s)/A(T) 换算后与 qfq@T 收盘比较（W-02 再乘 1−fail_pct）；禁止存某日 qfq 数值后跨除权日直接比较，不滚动重选。退出日 T 的收盘严格低于相应结构止损阈值才触发，等于阈值或仅盘中跌破不触发；最早 T+1 开盘卖出，以实际未复权开盘为参考价，扣减各卡 §18 的卖出滑点/冲击成本并另计费用。停牌、跌停无法卖出或无可卖量则保留指令，逐日顺延至第一个有可卖量且开盘可成交交易日的开盘；不开盘成交就继续顺延，不用盘中成交替代。连续多日一字跌停均记阻断、不记成交，不因后来价格恢复而撤销；复牌首日开盘可卖即执行，不受入场预热阻断，仍封跌停则继续顺延。成交证据未知则记未验证，样本末未退出的单列。三卡派生实现仍未验证，详见各卡 §7、§9、§17；S-01 v2 原无结构止损，不新增 X4。
