## 3. 风险排序（按对 P2N 闭环与做T复测数据的影响）

1. **读侧不可见**：日报和 today 读不到已落库行（证书 pending、licence_id 为空）。这是 P2N 闭环的直接阻断。[B140 T-B140b]
2. **复权因子缺失**：qfq 类卡、rc1 止损和复测都依赖它，麦蕊没有因子接口。[T81]、[R69 D1]
3. **单出口与熔断**：429、503、断连已多次触发回填熔断；日报 17:15 取数同样受影响，又不允许重试。[B140]、[T003 §11–12]
4. **回填覆盖**：完整 3 年只有 1,158 只主板；截面卡和全市场复测要等补完。[T81]
5. **退市股与幸存者偏差**：麦蕊取不到，复测结论只能降级，或改用 tdx 补源。[T003 GAP4]、[R69 D6]
6. **交易日历只有 2026 年**：缺日判定和 list_days 都依赖它。[T81 §1]
7. **ST 与成分只有当前值**：涨跌停 5%/10% 分段、rc4 和行业基准会出现时点偏差。[T81 §6]、[R70 N1]
8. **授权条款**：多用户分发边界未确认。[条款]

## 4. 交易日历、复权因子来源建议（优先不耗麦蕊）

### 4.1 交易日历
- **主源**：按 [multi-source-ingest.md](contracts/multi-source-ingest.md) §2.2 与 [trading-calendar-exrights.md](contracts/trading-calendar-exrights.md) §2，使用 DS `sessions.merged_calendar` 的合并日历。
- **核对源**：tdx-pack hsjday 里 sh000001.day 的交易日序列（1990-12-19 起，0 次麦蕊），只作核对、不定义日历。本单离线统计：2023 年 242 天，其中 11-13 以后 35 天；2024 年 242 天；2025 年 243 天；2026 年到 11-10 共 205 天。与 [T81] 麦蕊已观测的 35/242/243 天、2026 年到 11-13 的 208 天逐年一致。
- **未来年份**：用交易所年度休市安排公告补，具体链接未核（未验证）。
- **可选核对**：麦蕊 `/tcalendar/list/{年}`，3 年需 3 次调用，属于真调麦蕊，须用户本人批准。
- 复测前钉一份日历并记 sha [R69 D10]。

### 4.2 复权因子
- 与 T-A153 口径一致：**由 gbbq 统一算**。来源是 tdx 官网 gbbq.zip：1990 年起，7,416 个代码，已与 qlib 交叉核对 [SRC §三]。
- 算法：只取除权日 ≤ T 的事件，用前收算因子 [R69 D1]。
- 麦蕊 pc 与上一日收盘的比值，只作抽样交叉核对。依据：[T81 §6] 中 2,797 行 pre_close≠lag(close)，与除权事件相符；逐事件对齐未验证。
- 不存麦蕊 f 序列 [A136 §2]。
- gbbq 没有再分发许可，自用低风险 [SRC §三]。

### 4.3 沪深300 与基准
- 沪深300 主源用 tdx sh000300.day（2005-01-04 起，到 2026-11-10）；麦蕊 `/hsindex/history` 作日常增量（[B81] 已实测）。
- 中证全指 tdx 文件只到 2016-06-13，不可用；行业指数来源缺失。
